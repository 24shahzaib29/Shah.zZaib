How to Add or Edit Projects

All projects are cleanly rendered in index.html for zero-dependency speed and reliability.

To add a new project, copy and paste this block into the projects-grid in index.html:

<article class="glass-panel project-card">
  <div class="project-info">
    <h3 class="project-name">Your Project Name</h3>
    <p class="project-desc">Project description here.</p>
    <a href="#" class="btn btn-outline">View Project</a>
  </div>
</article>

Note: In purely static front-end apps, user-facing client-side forms cannot securely enforce administrative permissions. For secure visitor-facing updates, an authenticated server backend is required.
